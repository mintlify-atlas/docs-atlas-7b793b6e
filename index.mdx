## Get started

<Steps>
  <Step title="Open the site">
    Open `index.html` in your browser to view the AuraStyle store locally.
  </Step>
  <Step title="Browse the collection">
    Scroll to the **Productos** section to see the Spring/Summer collection with pricing.
  </Step>
  <Step title="Get in touch">
    Use the contact form in the **Contacto** section to send a message or inquiry directly to the team.
  </Step>
  <Step title="Customize">
    Edit the HTML and Tailwind configuration to update colors, products, or content.
  </Step>
</Steps>

<Tip>
  AuraStyle uses Tailwind CSS via CDN — no build step required. Just open `index.html` and you're live.
</Tip>
