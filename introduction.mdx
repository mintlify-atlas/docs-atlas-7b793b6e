AuraStyle is an Argentine fashion brand offering a Spring/Summer collection for the current season. The brand's site is a single-page storefront showcasing ready-to-wear pieces, the team behind the label, and channels to get in touch. Every garment is designed to express what the brand calls your "inner aura" — a distinct personal presence that fashion can amplify.

The current collection runs a **3% discount on all products**, making this the best time to explore the range.

<Note>
  AuraStyle's website is a fully static site. It requires no server, no build tool, and no package manager. Open `index.html` directly in any browser and it works immediately.
</Note>

## Technology stack

The site is built with three dependencies, all loaded from CDN:

| Layer | Technology | Source |
|---|---|---|
| Markup | HTML5 | — |
| Styling | Tailwind CSS | `cdn.tailwindcss.com` |
| Icons | Font Awesome 6.4.0 | cdnjs.cloudflare.com |

The Tailwind configuration is inlined in a `<script>` tag and extends the default theme with four brand colors:

| Token | Hex | Usage |
|---|---|---|
| `primary` | `#E11D48` | Accent text, buttons, highlights |
| `secondary` | `#1F2937` | Body text, navbar, footer |
| `accent` | `#F59E0B` | Supporting highlights |
| `light` | `#FDFBF9` | Page background |
| `dark` | `#111827` | Deep backgrounds |
